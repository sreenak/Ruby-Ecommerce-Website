HappiFashions
======
HappiFashions is a dress customisation and purchase e-commerce website built on ruby.

Setup:
-----
* Git clone: git clone ``````
* Copy ```env-example.txt``` file to ```.env```
* Edit ```.env``` file to include your own values
* Run ```bundle install```
* Run ```rake db:setup```
* Run ```rake db:migrate```
* Run ```rake db:seed```
